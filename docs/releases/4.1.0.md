# Release 4.1.0 — 2026-09-18

## Summary

Minor release adding merge-safe runtime model settings across Claude, Codex,
Cursor, and opencode; the opencode goal plugin; and shared Stripe, Xero, Linear,
Vercel, and Railway MCP servers. It also makes formatter execution deterministic
by resolving Node tools from the project's pinned `node_modules` binaries.

## Upgrade Notes

No breaking changes. Existing installations continue to work unchanged.

To apply the new merge-safe settings and MCP configuration to an existing
checkout, run the relevant sync command from the repository root, for example:

```bash
./install.sh sync --target all --intent settings,mcp
```

Unknown keys, provider credentials, and locally edited managed values are
preserved unless `--force` is supplied. For opencode, install the TUI half of the
goal plugin separately with `opencode2 plugin add
@prevalentware/opencode-goal-plugin` (or `opencode` if that is the V2 binary
name).
