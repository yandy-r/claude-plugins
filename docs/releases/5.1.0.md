# Release 5.1.0 — 2026-09-30

## Summary

Minor release. Patch releases under the `release-branches` model are now gated on a
backport audit: before `vX.Y.Z` is tagged, every trunk PR labelled `backport:X.Y` must
have a merged backport in `release/X.Y`, and every fix merged since the line's last tag
without the label needs an explicit decision. `/ycc:releaser` enforces it, and
`/ycc:backport --audit` runs it on its own.

## Added

## Changed

- `ycc:releaser`: a "Backport gate" after the branch check for every patch under
  release-branches. Missing or in-review backports stop the release; it fails closed when
  `gh` is unavailable.
- `ycc:backport`: new read-only `--audit [release/X.Y] [--since REF]` mode.
- `ycc:release-model`: the `RELEASING.md` template gains step 0 in the patch section
  ("Confirm every backport landed"); `--audit` check 13 flags files that lack it.
- `branching-model.md`: new "Before tagging a patch" rule.
